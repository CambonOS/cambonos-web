The ISO currently uses a shell-based installer. It offers two CambonOS desktop configurations developed by [Cambon18](https://github.com/Cambon18): [XFCE](https://github.com/Cambon18/xfce), recommended by the current installer, and [Qtile](https://github.com/Cambon18/qtile). Installer options and flow may change as the project evolves.

## Before you begin

- Back up important files.
- Make sure the ISO and computer are for the x86_64 architecture.
- Connect the computer to power and allow enough time for installation.

## Installation modes

The installer can install to a selected disk or use free space. **A clean-disk installation erases the contents of the selected disk.** Carefully review your selection before confirming.

The free-space option only works when the free area is at the end of the disk. If it is not at the end, the installer cannot use it correctly because it takes the final free space it detects and partitions there. The option requires a computer booted in UEFI mode. If you are unsure which option to choose, stop and get advice before changing partitions.

## Desktop environment

The XFCE and Qtile desktop configurations for CambonOS are developed by Cambon18. The current installer recommends XFCE; Qtile is also available. These are desktop configurations, not separate distribution editions.
