The ISO currently uses a shell-based installer. It offers Cambon18 with XFCE, recommended, or Qtile. Installer options and flow may change as the project evolves.

## Before you begin

- Back up important files.
- Make sure the ISO and computer are for the x86_64 architecture.
- Connect the computer to power and allow enough time for installation.

## Installation modes

The installer can install to a selected disk or use free space. **A clean-disk installation erases the contents of the selected disk.** Carefully review your selection before confirming.

The free-space option requires a computer booted in UEFI mode. If you are unsure which option to choose, stop and get advice before changing partitions.

## Desktop environment

XFCE is the installer’s recommended choice. Qtile is also available. This list reflects the options documented by the current installer; it does not imply other editions are available.
